# komardinec/topalike
Small script for showing most viable stats for Linux systems, including load average, CPU, Memory, Disk usage, top 5 processes by Mem and CPU usage

# Usage 
1) Clone the repository into your suitable directory:
``` bash 
git clone https://github.com/komardinec/topalike.git
# or
git clone git@github.com:komardinec/topalike.git
```
2) Change to downloaded directory and change execution flags:
``` bash
cd topalike
chmod +x server_stats.sh
```
3) Execute the script
``` bash
./server_stats.sh
```

Project idea from [roadmap.sh](https://roadmap.sh/projects/server-stats)
